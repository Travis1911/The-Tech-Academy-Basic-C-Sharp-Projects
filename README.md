## Projects

### Car Insurance

An ASP.NET MVC web application that simulates an insurance website. Users enter policy information and receive an automatically calculated insurance quote based on business rules.

Features:
- Insurance quote calculations
- Entity Framework database integration
- CRUD functionality
- Admin page for viewing issued quotes
- ASP.NET MVC architecture

Location:
`/CarInsurance`

### Student Database (Code First)

A console application built using Entity Framework Code-First development. The application creates a database and stores student records using C# classes.

Features:
- Entity Framework 6
- Code First workflow
- SQL Server LocalDB
- Student database creation
- Data persistence

Location:
`/Final Assignment`
